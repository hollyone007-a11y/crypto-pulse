# crypto-pulse — фьючерсный бот (лонг + шорт)

Анализирует USDT-M фьючерсы (Binance), торгует в обе стороны, каждую сделку проектирует под цель **+50% ROE** (к марже) и ведёт журнал для разбора.

## Как работает
1. **Тренд (4h):** EMA50/EMA200 + цена относительно EMA50 — обязательное условие, задаёт сторону (лонг/шорт).
2. **Вход (1h), балл до ~10:** EMA-стек, импульс MACD, зона RSI, сила тренда ADX, пробой 20-свечного уровня на объёме либо откат к EMA20. Входим при балле ≥ `min_score`.
3. **Сделка:** стоп 1.5·ATR, тейк 3.5·ATR (R:R ≈ 2.3). Плечо подбирается так, чтобы движение до тейка давало ≥ +50% к марже с учётом комиссий. Если для этого нужно плечо выше `max_leverage` (по умолчанию 10x) или ликвидация близка к стопу — **сделка пропускается**.
4. **Риск:** 1% депозита на сделку, лимит −5% в день, пауза после сделки, изолированная маржа.
5. **Глубокий разбор:** `report.py` — статистика по стороне, причинам выхода, каждому фактору входа, силе сигнала, MAE/MFE.

## Запуск
```bash
pip install -r requirements.txt
python -m pytest -q
python -m cryptopulse.cli backtest --symbol BTCUSDT          # реальные свечи с Binance
python -m cryptopulse.cli backtest --csv data/btc_1h.csv      # свои данные
python -m cryptopulse.cli run --mode paper                    # виртуальная торговля (по умолчанию)
python -m cryptopulse.cli run --mode live                     # реальные деньги (см. .env.example)
```

## Telegram
1. Создайте бота у @BotFather → `TELEGRAM_TOKEN`; свой id узнайте у @userinfobot → `TELEGRAM_CHAT_ID` (см. `.env.example`).
2. `export TELEGRAM_TOKEN=... TELEGRAM_CHAT_ID=...` и `python -m cryptopulse.cli telegram` (paper по умолчанию).
3. Команды: `/status` `/position` `/stats` `/report` `/backtest` `/pause` `/resume` `/help`. Бот сам присылает уведомления об открытии и закрытии сделок и об ошибках.
Отвечает только чатам из `TELEGRAM_CHAT_ID`, остальные игнорируются.

## Важно
- **+50% — это цель на сделку, а не гарантия.** Бот строит сделки с таким потенциалом, но часть будет закрыта по стопу (≈ −20…−25% ROE при риске 1% депозита). Прибыль зависит от винрейта: при R:R 2.3 нужен винрейт > ~30%.
- Плечо 10x усиливает и убытки. Не торгуйте суммой, которую жалко потерять.
- Бэктест в репозитории проверен только на **синтетических** данных (корректность кода, отсутствие заглядывания вперёд). Реальную эффективность нужно проверить на истории, затем на paper минимум 2–4 недели, затем live на минимальной сумме и testnet.
- `CcxtBroker` (live) написан, но **не тестировался на живой бирже**.
- Ключи API — без права вывода средств, храните в `.env`.
